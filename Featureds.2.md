ResistGate Extension — Feature Overview for SEO/Keywords

 🎯 Core Value Proposition

 ResistGate is a website blocker and digital discipline tool that prevents mindless browsing by intercepting visits to distracting sites and requiring intentional effort (typing challenges) to unlock temporary access. It builds real
 self-control through friction, not just barriers.

 ────────────────────────────────────────────────────────────────────────────────

 📋 FREE FEATURES (Core Experience)

 ### 1. Website Blocker / Site Blocker

 - Block any domain (YouTube, Reddit, Twitter/X, Instagram, TikTok, etc.)
 - Wildcard pattern matching support
 - "Block current tab" one-click blocking from popup
 - Persistent blocklist with management interface

 ### 2. Typing Challenge Unlock System

 - Complete a typing challenge to earn temporary access
 - 5 paragraphs of increasing difficulty
 - Full accuracy required — no shortcuts
 - Creates intentional friction to break autopilot browsing

 ### 3. Temporary Access Windows

 - Configurable duration (default: 15 minutes)
 - Automatic re-blocking after time expires
 - Visual countdown timer on success screen

 ### 4. Manual Override with Delay

 - Emergency override option with mandatory 10-15 second wait
 - Forces pause before giving in to impulse
 - Resistance counter tracks how many times you resisted

 ### 5. Schedule-Based Blocking

 - Set active hours for blocking (e.g., 9 AM — 5 PM)
 - Day-of-week selection (weekdays, weekends, custom)
 - Outside schedule = sites remain accessible

 ### 6. Daily Resistance Badge

 - Chrome toolbar badge shows daily blocked attempt count
 - Visual accountability — see your impulses in real-time
 - Resets daily at midnight

 ### 7. Work Timer / Focus Timer

 - Built-in productivity timer to track focused work sessions
 - Tracks daily minutes in focus mode
 - Pauses/resumes with session persistence

 ### 8. Resistance Counters

 - Per-site resistance tracking
 - Shows how many times you resisted visiting each blocked site today

 ### 6. Override Cooldown System

 - Progressive delay increases with frequent overrides
 - Configurable: 3-12 overrides in 1-24 hour window triggers lock
 - Lockout period: 5-180 minutes
 - Teaches restraint through consequences

 ### 7. Intention Page

 - Replaces block header with personal goal/reminder
 - Per-site goal setting
 - Optional 4-7-8 breathing exercise
 - Mindfulness integration for impulse control

 ### 8. Temptation Bundles

 - Conditional unlock rules per site:
     - Time-based: Unlock only after specific time (e.g., after 5 PM)
     - Work-timer-based: Unlock only after X minutes of focused work
 - Reward productive behavior with controlled leisure access

 ### 9. Accountability Presets

 - Light: Minimal friction for gentle reminders
 - Balanced: Moderate challenge (default)
 - Strict: Maximum friction for serious focus goals
