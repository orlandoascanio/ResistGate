Version 1.3.0

What changed for you

4 changes
01

Free for everyone

Free

Intention Page is now unlocked.

Your personal goal appears before you face the challenge.

The Intention Page — your saved reason, the breathing exercise, the pause before the decision — is now available to all users. New installs get it enabled by default. It's the most effective part of ResistGate, and it was hidden behind a paywall. Not anymore.

02

Visual refresh

UI

Friction page redesigned.

Know exactly where you are in the flow.

The blocked-site challenge page got a full visual overhaul. A progress stepper now shows which phase you're in — Pause → Prepare → Challenge → Access. The breathing exercise uses a refined ring animation. The challenge section has better visual hierarchy. Intentional design language throughout.

03

Usability

Settings

Options page reorganized.

Everything you need, exactly where you expect it.

The blocklist, friction controls, and intention settings are now grouped more logically. Site-specific goals live inline with each blocked site. The schedule section is cleaner. Everything is easier to find and faster to change.

04

First run

Onboarding

Welcome flow redesigned.

Cleaner introduction, faster setup.

The first-install onboarding is less static and more actionable. New users see a clearer path from adding their first site to understanding how the challenge works. The welcome card has better visual hierarchy and a more motivating tone.

Deep dive

The details

Intention Page goes free

Personal goals, breathing exercises, and the pause screen are now available to all users — not just Pro. The blocklist editor in options now supports inline goal setting per site.

Friction page redesign

Full visual overhaul of the blocked-site challenge page. Progress stepper shows which phase you're in (Pause → Prepare → Challenge → Access). Refined breathing ring animation and better visual hierarchy throughout.

Options page redesign

Reorganized panel structure, cleaner form layouts, improved accessibility for all interactive elements, and better visual hierarchy throughout.

Welcome page redesign

Fresh visual design with better information architecture. New users get a clearer understanding of the core value proposition in less time.
