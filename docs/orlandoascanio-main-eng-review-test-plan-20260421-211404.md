## Key Interactions to Verify
- Outcome tap appears in popup after temporary access expires (within 24h)
- Outcome tap does NOT appear if popup opened >24h after expiry
- Tapping Yes or No clears the pending key and records analytics event
- outcome_tap_response analytics event is preserved through storage read/write cycle
- Feedback links appear in all 3 locations and point to correct Google Form URL

## Edge Cases
- Access expires while popup is not open (most common case) → key persists until popup opens
- Multiple accesses expire before popup opened → most recent wins (last write wins)
- pendingOutcomeTap key is null or malformed → silent skip, no crash
- expiredAt is NaN or 0 → treated as expired, cleared

## Critical Paths
- `resistgate-access-expire-{domain}` alarm fires → `pendingOutcomeTap` written to storage
- Popup opens → reads storage → renders prompt if within 24h → user taps → key cleared
- `outcome_tap_response` event survives sanitizeAnalytics() without being remapped to access_granted
